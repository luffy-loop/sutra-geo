# SUTRA-GEO final prototype feature pack

## Core selection/demo flow
- India → state → city/district → clickable heritage node
- 50m geofence proof with distance, accuracy and unlock state
- Heritage Micro-Quest: 30-second node-specific quiz
- Quest completion → Sutra Coins → Passport journey update
- Repeat quest protection and anti-speed/location-consistency checks

## Heritage intelligence
- Curated heritage dataset with coordinates, categories, images, sources and verification status
- Location-aware Ask Sutra
- Source-backed heritage answers
- Explicit implemented vs future AI scope

## Personal journey
- Profile and username
- Profile photo
- Photo/video upload with captions
- Automatic city/node association from selected or current heritage context
- City Heritage Passport
- City media gallery and timeline
- Scrapbook filters for photos, videos, stories and saved places

## Living heritage
- Monuments, crafts, food, music, dance, festivals, oral history, local traditions and artisans
- Artisan profiles
- Traveller → artisan experience flow
- Community story submissions
- Moderation queue with Submitted → Under Review → Published/Verified states

## Rewards and impact
- +10 node discovery
- +30 Heritage Micro-Quest
- +20 verified community story
- +40 artisan experience
- Coin history
- Functional prototype redemption
- Impact dashboard with explicit Prototype Simulation label

## Deployment-readiness features
- Location privacy toggle and retention documentation
- Delete account and uploaded media controls
- Larger text, high contrast and text-to-speech
- English/Hindi/Telugu language preference demo
